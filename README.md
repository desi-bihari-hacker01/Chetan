# Chetan - Text to Speech Test

A small project to test text to speech in Python using pyttsx3. Still learning, so this is just a basic test for now.

## What it does

The script uses pyttsx3 to turn text into speech. Right now it speaks one fixed line:

"Good morning! Welcome to the Python Voice Assistant. How can I assist you today?"

Run it on your machine and it reads the line out loud.

## Why I made this

Wanted to learn how TTS works before building something bigger. This is me figuring out the basics - installing pyttsx3, setting up the engine, getting it to talk.

## About the web demo

pyttsx3 only runs locally, so it can't work in a browser or get hosted online. To let people try it without installing anything, I built a small web version using JavaScript's Web Speech API instead.

Live demo: https://desi-bihari-hacker01.github.io/Chetan/

Type text in the box, hit Speak, and your browser reads it out. Works best on Chrome or Edge.
